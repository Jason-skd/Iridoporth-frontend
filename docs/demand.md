# Iridoporth - 个人网站

## 整体风格

线条风, 卡其色质感
轻量, 简约

## 首页: 飞机舷窗

### 画面核心: 线条描绘的舷窗

用线条简单勾勒出飞机舷窗外场景

### 首页背景: 纸质感

纯色卡其色, 配有少量纹理, 模拟纸质感

### 标题: Iridoporth - 舷窗

字体足够醒目, 线条感
desktop 端一行文字, mobile 端拆分成两行
建议不要用字体实现, 用 assets 实现

## 下滑页: 树莓派状态页

### 核心文字呈现

树莓派 cpu 温度, 占用, 内存占用相关信息 (后端发送数据包, 5s 轮询)

### 共生背景

文字和背景共存
画面中心一颗孤独星球, 上空有一架飞机掠过
